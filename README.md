## 먼저 준비할 API · 계정 · 데이터

초기 데이터베이스는 비어 있습니다. 회사 계정, 거래, 직원, 과제 자료, API 키는 포함하지 않습니다.

| 준비 항목 | 설정 이름 | 필요한 기능 | 연결 전 동작 |
|---|---|---|---|
| Sites의 ChatGPT 로그인 | 플랫폼 인증 헤더, 사용자 계정 | 모든 서버 데이터 조회·변경 | 로그인 필요. 로컬 모의 로그인은 루프백 개발 환경 전용 |
| Cloudflare D1 | `DB` 바인딩 | 거래·분류·예산·요청서·설정 영구 저장 | DB 연결과 마이그레이션 필요 |
| Cloudflare R2 | `BUCKET` 바인딩 | 증빙·요청 첨부 파일 업로드·다운로드 | 거래/예산은 사용 가능. 파일 저장은 설정 오류 표시 |
| 본인 OpenAI API 계정 | `OPENAI_API_KEY`, `OPENAI_MODEL` | 지출/연구비 분류, 분개, 영수증 분할·매칭, 세금계산서 추출, 요청서 AI 초안·검토 | 수동 분류·편집은 가능. AI 버튼은 설정 오류 표시 |
| 본인 사업자등록번호 | 화면 설정 → 사업자등록번호 | 세금계산서 AI 추출 시 매출/매입 구분 | 미입력 시 추출 설정 오류 표시 |
| 본인 과제의 판정 가이드 | 화면 설정 → TIPS 판정 가이드 | 연구비 AI 분류·매칭·요청 검토 | 해당 AI 기능에서 가이드 입력 요청 |
| 본인 과제 정보 | 화면 설정 → 과제번호·과제명·기관·사업자번호·책임자·기간 | 연구비 요청서, 양식 내보내기 | 거래 분석은 가능. 과제번호 없는 요청 저장/양식 생성은 차단 |
| 본인 RCMS 실행 서비스 | `RCMS_ADAPTER_URL`, `RCMS_ADAPTER_TOKEN` | RCMS 등록 상태/시작 HTTP 연동 | 설정 오류 표시. RCMS 등록이 완료됐다고 표시하지 않음 |
| 로컬 RCMS companion | 사용자 실행 서비스가 제공하는 실행기 | 원래의 브라우저 실행기 연결 | 실행기를 이 저장소가 설치하거나 제공하지 않음. 전체 RCMS 제출은 별도 통합 검증 필요 |

외부 API 없이 가능한 핵심 기능: 명세서 가져오기, 중복 방지, 거래 조회·수정, 분류 규칙·사용자 카테고리, 예산, 지출/반복결제/계좌 분석, 내부이체 구분, 수동 증빙 연결(R2 필요), 거래 분할, TIPS 엑셀·거래 CSV·JSON 백업, 요청 작성·메시지·서식 생성. 금융기관/국세청 로그인 연동은 없으며 사용자가 내려받은 파일을 가져옵니다.

| 가져올 본인 자료 | 형식과 필수 식별 항목 |
|---|---|
| KB 국민카드 결제예정금액/매입·승인 내역 | `.xlsx`, `.xls`, `.csv`; 필수 원본 열: `승인일`, `가맹점명`, `합계` 또는 `승인금액`(원화 미확정 해외 결제는 null 유지). 승인번호가 있으면 중복 식별에 사용 |
| KB 은행 거래내역 / 회계 담당자 정리본 | `.xlsx`, `.xls`, `.csv`; 감지 필수 열: `거래일시`, `출금액`(단위 접미사 허용); `입금액`, `보낸분/받는분` 또는 `내용`과 `적요`를 보존합니다. 잔액은 선택. 계좌 분류를 위해 파일명에 `일반`, `TIPS` 또는 `팁스` 표기 |
| 홈택스 전자세금계산서 목록 | `.xlsx`, `.xls`, `.csv`; `작성일자`, `공급가액` 또는 `합계금액`; `세액`, `공급자상호`(매입)/`공급받는자상호`(매출), 사업자등록번호, `승인번호`를 보존. 파일명/시트명에 `매출` 또는 `매입` 포함 |
| RCMS 연구비 이체결과 | `.xlsx`; `과제번호`, `이체일시`, `사용금액`, `비목정보`, `지급용도`, `입금계좌`, `거래처명`, `이체상태`, `품목명` 원본 열 |
| 영수증/연구비 증빙 | PDF, 이미지, Office·한글 문서 등; 20MB 미만. 파일명에 거래일·거래처·서류종류가 있으면 원래의 이름 매칭 사용. AI 내용 판독은 이미지/PDF 지원 |

세부 헤더 별칭과 원본 형식 감지는 `lib/finance/parse.ts`와 `lib/finance/rcmsParse.ts`에 보존되어 있습니다. 일반 임의 CSV를 표준 원장으로 자동 해석하는 기능은 없습니다. 업로드는 미리보기 후 확정합니다.

## 로컬 실행

Node.js 22.13 이상과 npm을 준비합니다.

```sh
npm ci
npm run build
npm run db:migrate
npm run dev -- --port 5173
```

`http://127.0.0.1:5173`에서 로컬 ChatGPT 로그인 흐름으로 접속합니다. `db:migrate`는 `wrangler.local.json`에 선언된 `DB`에 커밋된 Drizzle 마이그레이션을 순서대로 적용하며, 이미 적용한 마이그레이션은 다시 실행하지 않습니다. 새 마이그레이션은 스키마를 변경했을 때만 `npm run db:generate`로 생성합니다.

마이그레이션, Vite 개발 서버와 `npm start`는 모두 동일한 DB 식별자와 `.wrangler/state` 저장 경로를 사용합니다. Vite의 `persistState`에도 이 경로가 명시돼 있습니다. DDL은 요청 처리 중에 실행하지 않습니다. `npm start`는 빌드된 Worker 실행용이며, 플랫폼 인증 프록시가 없는 로컬 환경에서는 모의 로그인을 제공하지 않습니다.

선택 기능을 연결하려면 [`.env.example`](.env.example)을 `.dev.vars`로 복사하고 본인 값만 입력합니다. 외부 API 없이 핵심 기능을 사용할 때는 이 파일이 필요하지 않습니다. 배포에서는 플랫폼의 서버 Secret 설정을 사용합니다. 키 이름만 다음처럼 준비합니다. 프런트엔드 변수(`NEXT_PUBLIC_*`)에 키를 넣지 마세요.

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=
RCMS_ADAPTER_URL=
RCMS_ADAPTER_TOKEN=
```

루프백 개발 서버의 ChatGPT 로그인 버튼으로 로그인한 후 `설정` 화면에서 과제 정보·TIPS 가이드를 저장하고 본인 자료를 가져옵니다. Sites의 `.openai/hosting.json`은 기존 개인용 Site 식별자를 유지하며 `d1: DB`, `r2: BUCKET`을 사용합니다. 운영 마이그레이션과 Secret 연결은 배포 담당자가 실행해야 합니다.

RCMS HTTP 어댑터는 구성된 URL의 `/registration`에 Bearer 인증으로 `operation: state|start`, `requestId`, `owner`, 선택적 `verificationOnly`를 전달합니다. 응답은 원래 `lib/rcms/types.ts`의 상태/작업/launch 계약을 따라야 합니다. 이 저장소에는 RCMS 사이트 로그인 자동화 프로그램이나 정부 시스템 연결 계정이 포함되지 않습니다.

## 업무 흐름

| 화면 | 실제 업무 |
|---|---|
| 대시보드 | 월별 요약·누적 사용액·최근 거래에서 원장 상세로 이동 |
| 반복 결제 / 지출 분석 | 3개월 이상 같은 가맹점의 사용 이력, 분류별 지출과 추이 확인 |
| 예산 | 분류별 예산을 입력하고 서버에 저장, 실제 지출 대비 비교 |
| 계좌·카드 / 거래 내역 | 파일 기반 계좌 잔액, 필터·수동 분류·사용자 분류·분류 규칙과 상세 수정 |
| 지출 분석(내부) | 카드대금·내부이체 중복 제외, 분할·분개와 증빙 확인 |
| TIPS | 매월 9일~다음 달 8일 창, 수동 판정과 증빙·분할, 검토 후 AI 결과 적용 |
| 연구비 요청 / 요청 내역 / 사후 증빙 | 거래 기반 요청서 작성, 필수 서류·메시지 관리, Excel 양식 생성과 구매 후 사진 추적 |
| 설정 | 사용자 과제·기관·사업자번호·기간, 본인 판정 가이드와 가맹점 별칭 저장 |

## 검증과 범위

React/Vinext의 원래 Finance 화면 → 인증된 API → D1 `finance_records`의 사용자별 원장 구조입니다. 파일은 사용자별 R2 경로에 저장합니다. 외부 비밀값은 서버에서만 사용하며 브라우저에는 전달하지 않습니다. 원래 `lib/data/finance.ts` 함수 계약과 파서/무결성 모듈을 유지하고 Supabase 연결을 HTTP/D1로 교체했습니다.


```sh
npm run typecheck
npm test
npm run build
```

실행 중인 루프백 개발 서버의 HTTP/R2 검증은 `FINANCE_TEST_URL=http://127.0.0.1:5173 node scripts/test-http.mjs`로 수행합니다. 테스트는 임시 원장/파일을 만들고 정리합니다. 외부 유료 호출을 하지 않습니다.

원래 화면/알고리즘 보존 내역은 `docs/FEATURE-PARITY.md`, 실제 검증 결과와 남은 통합 제한은 `docs/IMPLEMENTATION-REPORT.md`를 확인하세요. AI 유료 호출, 이메일 전송, 실제 은행/회사 데이터 및 RCMS 제출은 테스트하지 않습니다. 원본 SheetJS 0.20.2 파서 패키지와 포함된 라이선스를 유지합니다. 브라우저에서 빈 화면과 예산 저장·새로고침 후 유지 동작을 확인했습니다. 실제 사용자 외부 계정 연결과 RCMS 제출은 별도로 검증해야 합니다.
